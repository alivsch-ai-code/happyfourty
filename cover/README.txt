Hier liegt fuer jeden Song im Player ein eigenes Cover-Bild.

Aktuell zeigen alle Dateien noch das gleiche Platzhalter-Bild (template.jpg).
Willst du fuer einen Song ein eigenes Cover setzen, ersetze einfach die
passende Datei durch dein eigenes Bild (gleicher Dateiname, gerne auch
.jpg oder .png):

01-intro.jpg                   -> Intro - Roman anstatt Alex
02-zwei-geburtstage.jpg        -> Zwei Geburtstage, ein Ziel
03-auf-unsern-nacken.jpg       -> Auf unser'n Nacken
04-wird-zu-gold.jpg            -> Wird zu Gold
05-roman-wird-vierzig.jpg      -> Roman wird vierzig (Cover)
06-alles-gute-roman.jpg        -> Alles Gute, Roman
07-banja-in-den-bergen.jpg     -> Banja in den Bergen
08-banya-gangster.jpg          -> Banya-Gangster
09-schwarzer-bumer.jpg         -> Чёрный Бумер (Флизинлегер-мэн)
10-shurik-ist-gluecklich.jpg   -> Shurik ist glücklich

Kein Code-Update noetig - die Dateinamen sind bereits im Player verdrahtet.
Willst du einen neuen Song ergaenzen, kopiere template.jpg unter einem
neuen Namen und trage den Dateinamen im "PLAYLIST CONFIG"-Abschnitt in
index.html bei "cover" ein.
